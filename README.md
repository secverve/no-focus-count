# No Focus Count

집중할 macOS 창을 지정하고 뽀모도로를 시작하면, 다른 앱이나 창으로 벗어난 동안 타이머를 자동으로 멈추고 이탈 횟수와 시간을 로컬에 기록하는 개인정보 보호 중심 앱입니다.

## 현재 MVP 기능

- 5~120분 뽀모도로 타이머와 호버 기반 다크 UI
- 다른 앱 위에 띄워두는 항상 위 미니 타이머
- 브라우저와 전체화면 작업 공간 위에서도 포커스를 빼앗지 않는 시간 오버레이
- 완료 시 소리, macOS 알림, Dock 주의 표시
- 지정한 창과 다른 앱·창을 사용하면 자동 일시정지
- 여러 모니터 전체의 창 순서와 가림 정도를 샘플링해 집중 창 노출 비율 계산
- 집중 창으로 돌아오면 타이머 자동 재개
- 세션별 집중 시간, 이탈 횟수, 이탈 시간, 앱 이름, 창 제목 기록
- 명시적으로 동의한 경우 Safari, Chrome, Brave, Edge의 현재 탭 URL 기록
- 명시적으로 동의한 경우 2초 이상 이어진 이탈 창을 저해상도 1장으로 남기는 Focus Receipt
- 이름별 로컬 집중왕·딴짓왕 랭킹과 집중 콤보, 세션별 재미 문구
- 지난 세션 상세 내역과 전체 삭제
- 서버 없이 `~/Library/Application Support/NoFocusCount/sessions.json`에만 저장

키 입력, 페이지 본문, SNS 내용은 수집하지 않습니다. Focus Receipt를 끄면 화면 이미지도 전혀 수집하지 않습니다.

## 실행

macOS 14 이상과 Swift 5.10 이상이 필요합니다.

```bash
sh Scripts/build-app.sh
open dist/NoFocusCount.app
```

처음 실행하면 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 `No Focus Count`를 허용하세요. 브라우저 URL 기록을 켜면 macOS가 해당 브라우저 자동화 권한을 별도로 요청할 수 있습니다.

Focus Receipt는 기본적으로 꺼져 있습니다. 설정에서 직접 켜면 macOS가 **화면 및 시스템 오디오 기록** 권한을 요청하며, 권한 허용 후 앱을 다시 실행해야 할 수 있습니다. 이 기능은 영상을 녹화하지 않고 이탈이 2초 이상 유지된 시점에 해당 창 한 장만 480px JPEG로 로컬 저장합니다.

macOS가 개인정보 보호를 위해 창 제목을 제공하지 않는 경우에도 해당 창은 `앱 이름 — 제목 없는 창 #번호`로 선택 목록에 표시됩니다.

앱의 창 목록에서 공부에 사용할 창을 선택한 후 **집중 시작**을 누르면 앱이 선택한 창을 앞으로 가져오고 2초 뒤 측정을 시작합니다.

## 개발 및 검증

```bash
# 전체 XCTest — Xcode가 설치된 환경
swift test

# Command Line Tools만 있는 환경의 핵심 정책 검사
sh Scripts/test-core.sh
```

이 저장소가 있는 Mac의 Command Line Tools에서 SwiftPM 링크 산출물 문제가 발생할 경우에도 `Scripts/build-app.sh`는 `swiftc`로 직접 앱 번들을 생성합니다. GitHub Actions에서는 전체 XCTest와 앱 빌드를 모두 검증합니다.

## 판정 방식과 제한

- 선택한 창이 현재 활성 창이고 설정한 비율 이상 노출될 때만 집중 시간으로 계산합니다.
- 대상 창이 닫히거나 최소화되거나 다른 앱·창을 사용하면 자동으로 멈춥니다.
- 가림 비율은 macOS 창 목록을 격자로 샘플링한 근사값입니다. 투명 창이나 특수 오버레이에서는 실제 체감과 다를 수 있습니다.
- Firefox 등 AppleScript로 현재 탭 URL을 제공하지 않는 브라우저는 앱·창 제목까지만 기록합니다.
- App Store 배포 전에는 Developer ID 서명, 공증, 권한 안내 검토가 추가로 필요합니다.

## 개인정보 원칙

- 기록은 로컬 JSON 파일에만 보관합니다.
- URL 기록은 기본적으로 꺼져 있으며 사용자가 켜야 합니다.
- Focus Receipt도 기본적으로 꺼져 있으며 사용자가 켠 경우에만 저해상도 이탈 창 이미지를 저장합니다.
- 네트워크 전송이나 분석 SDK가 없습니다.
- 앱 안에서 모든 기록을 삭제할 수 있습니다.
